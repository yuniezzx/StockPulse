## 60 日新高 / 新低

60 日新高 / 新低基于前复权收盘价 `close_qfq` 判断当前价格是否达到最近 60 个交易日的最高或最低水平。A 股 60 个交易日约等于 3 个月，适合识别强势突破与趋势破位。

### 公式

$$
\text{rolling\_max}_{60,t} = \max(\text{close\_qfq}_{t-59}, \ldots, \text{close\_qfq}_t)
$$

$$
\text{rolling\_min}_{60,t} = \min(\text{close\_qfq}_{t-59}, \ldots, \text{close\_qfq}_t)
$$

$$
\text{is\_new\_high\_60d}_t = \text{close\_qfq}_t \ge \text{rolling\_max}_{60,t}
$$

$$
\text{is\_new\_low\_60d}_t = \text{close\_qfq}_t \le \text{rolling\_min}_{60,t}
$$

### 例子

窗口包含当日，第 60 天开始才输出布尔值：

| 日期 | close_qfq | 60 日最高 | 60 日最低 | is_new_high_60d | is_new_low_60d |
|------|-----------|-----------|-----------|-----------------|----------------|
| 第 1 天 | 10.0 | null | null | null | null |
| ... | ... | ... | ... | null | null |
| 第 59 天 | 12.0 | null | null | null | null |
| 第 60 天 | 13.0 | 13.0 | 10.0 | true | false |
| 第 61 天 | 9.5 | 13.0 | 9.5 | false | true |

第 60 天：`close_qfq=13.0` 等于包含当日在内的 60 日最高价，因此 `is_new_high_60d=true`。

### 函数签名

```python
compute_new_high_low(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/momentum.py`。

### 参数说明

- df — 含 ts_code / trade_date / close_qfq，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `is_new_high_60d` | 60 日 | close_qfq 是否达到最近 60 日最高价 |
| `is_new_low_60d` | 60 日 | close_qfq 是否达到最近 60 日最低价 |

### 注意事项

- 基于 `close_qfq`，不使用 `high_qfq` / `low_qfq`，避免盘中极值与收盘突破信号混淆
- 窗口包含当日：使用最近 60 个交易日（第 t-59 天至第 t 天）滚动最高 / 最低
- 比较使用 `>=` / `<=`，等于 60 日最高 / 最低也算新高 / 新低
- 前 59 天严格为 NULL，因为不足完整 60 日窗口
- 多股隔离：按 `ts_code` 分组计算，不跨股票串联窗口
- 用途：`is_new_high_60d` 常用于强势突破识别，`is_new_low_60d` 常用于趋势破位预警
