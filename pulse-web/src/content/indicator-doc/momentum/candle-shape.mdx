## K 线形态

K 线形态由跳空幅度与实体幅度组成，用来描述当日开盘相对前收盘的位置，以及收盘相对开盘的方向与幅度。两者都基于 qfq 价格计算，单位为小数（0.05 = 5%）。

### 跳空幅度

公式：

$$
\text{gap\_pct}_t = (\text{open}_t - \text{close}_{t-1}) / \text{close}_{t-1}
$$

例子：

| 日期 | open_qfq | prev_close_qfq | gap_pct |
|------|----------|----------------|---------|
| 第 1 天 | 10.0 | null | null |
| 第 2 天 | 10.5 | 10.0 | 0.05 |
| 第 3 天 | 9.8 | 10.0 | -0.02 |

第 2 天开盘价相对前一日收盘价向上跳空 5%；第 3 天向下跳空 2%。

### 实体幅度

公式：

$$
\text{body\_pct}_t = (\text{close}_t - \text{open}_t) / \text{open}_t
$$

例子：

| 日期 | open_qfq | close_qfq | body_pct |
|------|----------|-----------|----------|
| 阳线 | 10.0 | 10.8 | 0.08 |
| 阴线 | 10.0 | 9.6 | -0.04 |

实体幅度带方向：收盘高于开盘为正，收盘低于开盘为负，用于区分阳线与阴线。

### 函数签名

```python
compute_candle_shape(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/momentum.py`。

### 参数说明

- df — 含 ts_code / trade_date / open_qfq / close_qfq，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `gap_pct` | 单日 | 开盘价相对前一交易日收盘价的跳空幅度，单位=小数 |
| `body_pct` | 单日 | 收盘价相对开盘价的实体幅度，单位=小数，带方向 |

### 注意事项

- 使用 qfq 价格：基于 `open_qfq` / `close_qfq`，避免除权除息造成形态失真
- 单位为小数：0.05 表示 5%，与 `pct_chg` 保持一致
- 首日 `gap_pct = NULL`：首日没有前收盘价，不填充为 0
- `body_pct` 带方向：正值代表阳线，负值代表阴线
- 多股隔离：按 ts_code 分组计算前收盘价，避免跨股票串联
