<h2 id="pct-chg">N 日涨跌幅</h2>

N 日累计涨跌幅衡量当前复权收盘价相对 N 个交易日前的累计变化。指标基于 `close_qfq` 计算，单位为小数（0.05 = 5%）。

### 公式

$$
\text{pct\_chg\_5d}_t = \frac{\text{close\_qfq}_t}{\text{close\_qfq}_{t-5}} - 1
$$

$$
\text{pct\_chg\_20d}_t = \frac{\text{close\_qfq}_t}{\text{close\_qfq}_{t-20}} - 1
$$

### 例子

| trade_date | close_qfq | pct_chg_5d |
|------------|-----------|------------|
| 第 1 天 | 10.0 | null |
| 第 2 天 | 10.5 | null |
| 第 3 天 | 10.3 | null |
| 第 4 天 | 10.8 | null |
| 第 5 天 | 11.0 | null |
| 第 6 天 | 10.9 | 0.09 |
| 第 7 天 | 11.2 | 0.0667 |

第 6 天：$10.9 / 10.0 - 1 = 0.09$，即 9%。第 7 天：$11.2 / 10.5 - 1 \approx 0.0667$，即 6.67%。

### 函数签名

```python
compute_pct_chg(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/momentum.py`。

### 参数说明

- df — 含 ts_code / trade_date / close_qfq，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `pct_chg_5d` | 5 日 | 5 个交易日累计涨跌幅 |
| `pct_chg_20d` | 20 日 | 20 个交易日累计涨跌幅 |

### 注意事项

- 单位为小数（0.05 表示 5%），符合 migration 011 注释
- 使用 qfq 价格：避免除权除息日造成假涨跌
- 前 N 行 NULL：无法回看 N 天
- 不计算 1d：日表 daily_cn 本身已有 pct_chg 列，避免重复
- 多股隔离：按 ts_code 分组计算
