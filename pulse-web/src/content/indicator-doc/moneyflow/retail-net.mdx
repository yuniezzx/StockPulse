## 散户净额

散户（小单 + 中单）净流入与主力净流入对照，可识别"主力吸筹散户卖出"等量价分歧场景。本字段仅给金额，比例与均值留待业务侧组合使用。

### 公式

$$
\text{retail\_net\_amount}_t = (\text{buy\_sm} + \text{buy\_md}) - (\text{sell\_sm} + \text{sell\_md})
$$

### 例子

构造一行：buy_sm=100 万 + buy_md=50 万，sell_sm=80 万 + sell_md=70 万，则 retail_net = 0 万元（净中性）。

| 项目 | 金额（元） |
|------|------------|
| buy_sm_amount | 1,000,000 |
| buy_md_amount | 500,000 |
| sell_sm_amount | 800,000 |
| sell_md_amount | 700,000 |
| retail_net_amount | 0 |

### 函数签名

```python
compute_retail_net(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/moneyflow.py`。

### 参数说明

- df — 含 ts_code / trade_date / buy_sm_amount / buy_md_amount / sell_sm_amount / sell_md_amount，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `retail_net_amount` | 单日 | 散户净流入金额，单位=元 |

### 注意事项

- 散户 = 小单（&lt;5万）+ 中单（5万–20万），与 moneyflow_cn 单类规则一致
- 与 main_net_amount 配对使用：观察"主力流入 + 散户流出"等分歧场景归 `screener/`
- 不做 ratio：散户金额跨股本规模差异极大，业务侧若需对比通常用主力 ratio
- 不做 ma5：保留原始日序列，业务侧可灵活计算任意周期
- NaN 自然传播（moneyflow_cn 缺失行 ingestion 不写）
- 主力散户合计净额与 moneyflow_cn.net_mf_amount 在数学上恒等（差异即为单位/精度噪音）
