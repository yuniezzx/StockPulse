## PE/PB 分位

估值绝对值（PE=20、PB=2）跨行业难比较。60 日滚动分位将当前估值定位在该股近期估值分布中，给出 [0, 1] 相对值，便于"逢低布局"或"高位预警"。

### 公式

$$
\text{pct}_t = \frac{\text{rank}_t - 1}{n - 1}, \quad n = 60
$$

rank 为当前值在 60 日窗口（含当日）内升序排名。

### 例子

构造 60 日 PE_TTM 单调递增 [10.0, 10.1, ..., 15.9]，第 60 天 PE_TTM = 15.9 排名 60 → pct_60 = (60-1)/59 = 1.0。

| 日期 | pe_ttm | rank | pe_ttm_pct_60 |
|------|--------|------|---------------|
| 第 58 天 | 15.7 | 58 | null |
| 第 59 天 | 15.8 | 59 | null |
| 第 60 天 | 15.9 | 60 | 1.0 |
| 中间某天 | 12.9 | 30 | 0.49 |

### 函数签名

```python
compute_pe_pb_quantile(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/volume.py`。

### 参数说明

- df — 含 ts_code / trade_date / pe_ttm / pb，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `pe_ttm_pct_60` | 60 日 | PE_TTM 当前值 60 日分位，单位=小数 [0,1] |
| `pb_pct_60` | 60 日 | PB 当前值 60 日分位，单位=小数 [0,1] |

### 注意事项

- 闭区间 [0, 1]：rank=1 → 0.0（最低分位），rank=n → 1.0（最高分位）
- 严格 NULL warmup：前 59 行 NULL（窗口不足）
- 严格有效样本：窗口内任一 NaN（停牌/亏损 PE 缺失）→ 该位置 NULL
- 负值正常排名：亏损股 PE 为负仍参与排名，不做符号过滤（业务侧若需排除负 PE，归 `screener/`）
- 与 60 日新高/新低（momentum）使用同样的 rolling 60 含当日口径
- 多股隔离：按 ts_code 分组计算
