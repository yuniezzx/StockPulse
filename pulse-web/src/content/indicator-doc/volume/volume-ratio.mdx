## 成交量均值与量比

成交量是市场参与度的直接度量。短中线交易常用 5/10 日均量识别"温和放量"或"突破放量"，量比衡量当日成交量相对近期均值的活跃程度。

### 公式

$$
\text{vol\_ma}_n = \frac{1}{n}\sum_{i=0}^{n-1} \text{vol}_{t-i}
$$

$$
\text{vol\_ratio}_5 = \frac{\text{vol}_t}{\text{vol\_ma5}_t}
$$

### 例子

构造 5 日 vol 序列 [1.0e8, 1.2e8, 0.9e8, 1.1e8, 2.0e8]，第 5 天 vol_ma5 = 1.24e8，vol_ratio_5 = 2.0e8 / 1.24e8 ≈ 1.61。

| 日期 | vol | vol_ma5 | vol_ratio_5 |
|------|-----|---------|-------------|
| 第 1 天 | 1.0e8 | null | null |
| 第 2 天 | 1.2e8 | null | null |
| 第 3 天 | 0.9e8 | null | null |
| 第 4 天 | 1.1e8 | null | null |
| 第 5 天 | 2.0e8 | 1.24e8 | 1.61 |

第 5 天：$\text{vol\_ma5} = (1.0 + 1.2 + 0.9 + 1.1 + 2.0) \times 10^8 / 5 = 1.24 \times 10^8$。

### 函数签名

```python
compute_vol_ma(df: pd.DataFrame) -> pd.DataFrame
```

位于 `pulse_core/indicators/volume.py`。

### 参数说明

- df — 含 ts_code / trade_date / vol，已按 ts_code + trade_date 排序

### 输出列

| 字段 | 窗口 | 含义 |
|------|------|------|
| `vol_ma5` | 5 日 | 成交量 5 日均值，单位=股 |
| `vol_ma10` | 10 日 | 成交量 10 日均值，单位=股 |
| `vol_ratio_5` | 5 日 | 当日成交量 / vol_ma5，单位=无 |

### 注意事项

- 成交量无复权语义，直接用 daily_cn.vol，不做前复权处理
- 严格 NULL warmup：vol_ma5 前 4 行 NULL，vol_ma10 前 9 行 NULL
- 除零防御：vol_ma5 == 0 时 vol_ratio_5 = NULL（停牌或集合竞价归零的极端情况）
- 量比阈值（如 ">2 倍"）属于策略决策，归 `screener/` 处理
- 多股隔离：按 ts_code 分组计算
